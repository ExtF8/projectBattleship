# Battleship Project

## Introduction

This project is part of [The Odin Project](https://www.theodinproject.com/lessons/node-path-javascript-battleship) and focuses on creating a fully interactive Battleship game. It implements essential features such as ship placement, attack handling, and win/loss conditions while adhering to the principles of clean and modular code. The project emphasizes separating game logic from the user interface, promoting maintainable and testable code.

### Features

- Implementation of the core Battleship game mechanics:
  - Ship placement on gameboards.
  - Handling attacks and tracking hits, misses, and sunk ships.
  - Win/loss detection based on all ships being sunk.
- Visual representation of gameboards with ships and attacks.
- Dynamic UI updates based on game state changes.
- Separation of application logic and DOM manipulation for cleaner architecture.
- Randomized ship placement for AI players.
- **Test-Driven Development (TDD):**
  - Comprehensive unit tests for key game logic components.
  - Ensures robustness of ship placement, attack handling, and game state transitions.
